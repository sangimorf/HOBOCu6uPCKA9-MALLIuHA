# 🧠 HOBOCu6uPCKA9 MALLIuHA (MindMap Editor)

**Кроссплатформенный редактор интеллект-карт** с поддержкой векторной графики, гибкой кастомизации и интеграцией с нейросетями (через JSON). 

## 🚀 Обновление 1.0.3

- 📏 **Длина строки (lineWidth):** В меню ПКМ добавлена настройка «Длина строки». Теперь можно вручную задавать, сколько символов помещается в одну строку текста, не растягивая при этом саму фигуру визуально. Настройка сохраняется в JSON.
- ⚡ **Оптимизация производительности:** Полностью переписан движок перетаскивания и панорамирования (камеры). Устранены лаги при движении мыши и перетаскивании узлов за счет применения `requestAnimationFrame` и аппаратного ускорения CSS.
- 📐 **Пропорции для всех фигур:** Возвращена и улучшена возможность изменять ширину и высоту (`stretchX`, `stretchY`) для прямоугольников.
- 🛠 **Исправлена верстка текста:** В развернутом состоянии (`[+]`) текст больше не обрезается многоточием. Узел растет ровно настолько, насколько нужно для отображения всего текста.

## ✨ Основные возможности

- **Векторная графика:** Прямоугольники, эллипсы и ромбы, которые легко перетаскивать и масштабировать.
- **Умные узлы:** Автоматический перенос текста и возможность сворачивать/разворачивать длинные описания.
- **Навигация:** Плавный зум (Ctrl + колесико) и панорама (зажатое колесико).
- **Кастомизация:** Настройка цветов фона, шрифтов, толщины и цвета линий связей, а также пропорций и длины строки.
- **Сохранения:** Локальное сохранение карт в файлы `.mindmap` / `.json`.
- **Магия ИИ:** Импорт и экспорт JSON-шаблонов для генерации целых карт нейросетями.
- **Гиперссылки:** Возможность прикреплять ссылки к узлам.
- **Локализация:** 17 языков интерфейса (включая окно "О программе").

## 🛠️ Управление

- **Ctrl + колесико мыши** — Приблизить / Отдалить
- **Зажатое колесико мыши** — Перемещение по карте (Панорама)
- **Правая кнопка мыши** — Меню элемента (цвет, форма, размер, пропорции, длина строки)
- **Двойной клик** — Редактировать текст и ссылки
- **Левый клик + перетаскивание** — Двигать элементы
- **Кнопка [+] / [-] на узле** — Свернуть / Развернуть текст
