# HOBOCu6uPCKA9-MALLIuHA (MindMap Editor)

Кроссплатформенный редактор интеллект-карт с поддержкой векторной графики, гиперссылок, кастомизации и импорта/экспорта через JSON (в том числе для генерации карт нейросетями).

## ✨ Возможности
- Векторная графика (прямоугольники, эллипсы, ромбы).
- Умные узлы: авто-размер, сворачивание/разворачивание, перенос текста.
- Зум (Ctrl + колесико) и панорама (зажатое колесико).
- Гиперссылки, которые открываются в браузере.
- Гибкая настройка: цвета фона/шрифта/линий, толщина связей.
- Сохранение и загрузка карт в файлы `.mindmap` / `.json`.
- Интеграция с ИИ: генерация целых карт по JSON-шаблону.
- Поддержка 12 языков интерфейса.

## 🛠️ Стек
- **Frontend:** Vanilla JavaScript, SVG, Vite
- **Backend:** Rust (Tauri v2)
- **OS:** Linux (Artix/Arch), Windows, macOS
